# YP Nepal

YP Nepal is a business directory platform designed to help users discover businesses and services by category, location, and search.

## Overview

The platform is built with Laravel, Inertia.js, Vue.js, and MySQL/MariaDB. It combines traditional directory search with AI-powered search to make it easier for users to find relevant businesses and services.

## Live Website

https://ypnepal.com.np/

## Features

- Business and service directory
- Category-based search
- Location-based search
- Business listings
- Business categories and locations
- AI-powered search
- Admin management
- Excel data import
- Database-driven search
- Responsive user interface
- REST API integration

## Technology Stack

- **Backend:** PHP, Laravel
- **Frontend:** Vue.js, Inertia.js
- **Database:** MySQL / MariaDB
- **JavaScript:** JavaScript
- **AI:** AI API integration
- **Web Server:** Linux / cPanel / LiteSpeed

## Project Structure

The application follows a Laravel-based architecture with separate backend logic, frontend pages, database models, controllers, routes, and resources.
